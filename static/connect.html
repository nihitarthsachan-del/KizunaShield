Connect your network

Pick the way you want KizunaShield to see your exposure. All three feed the same scoring engine and the same compliance report — the difference is how much access each one needs.

Scan a range you already own

You give us a CIDR block or a list of domains, we run the same exposure scan we run against the demo orgs and score the result the same way.

  • Only scans ranges you explicitly list
  • Read-only reconnaissance — no exploitation
  • Results feed the same dashboard and PDF report

Install one lightweight agent

Run a single small agent on any machine inside the network. It reports what it can see internally — no inbound port ever has to be opened for us.

  • Outbound-only — nothing listens for connections
  • One binary, one machine, no per-endpoint install
  • You control what it's allowed to look at

This install command is a placeholder — the agent build and hosted installer aren't part of this demo yet.

Connect without installing anything

We look up what's already publicly exposed about your domain through passive sources — nothing is sent to your network, nothing is installed.

  • No scanning traffic ever reaches your network
  • Based on public exposure data tied to your domain
  • Lowest access, also the least complete picture
